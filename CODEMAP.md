# CODEMAP: Unnamed Municipality EMS Callout Helper

Single-file browser tool. No dependencies. Node is only needed to build and test. The schedule source of truth is an Aladtec iCal (.ics) file; nothing about shifts is stored in the tool.

| Path | What it is |
| --- | --- |
| `Callout Helper.html` | Built output, the shareable file. Generated by `tools/build.js`, so don't hand-edit. Embeds the made-up sample .ics for the "Try it" button. |
| `src/engine.js` | All logic (UMD: Node `require` or `window.CalloutEngine`). `importICS(text)` reads VEVENTs into records `{name,start,end,kind:'work'/'slot'/'event',forName}`. Times are "wall minutes" (local clock time as minutes, so DST doesn't move shifts). All-day items become day labels. Trades come from "X for Y" in the summary or "For Y" in the description. Placeholders (Fifth Provider, Tentative Approval, Ride Along, Medic units) match `SLOT_RE`. `makeSchedule` and `withInference` -> `infer(sc)`: the per-day shift label, each person's owned hours (trades count for the owner), guessed role (120+ h per 28 days means FT), home label (75%+ of owned hours, otherwise Kelly crew), and untraded days off on their own label. `computeCallout(opts)` applies RULES.md; `candidates(sched, saved)` is the one list of people the engine can offer and the tick-box table shows (schedule people plus saved full-timers missing from the file, minus "Not on the lists"); `legalSet(shifts, free)` finds the hours of an opening someone may work within the 96-hour limit as one jointly safe set; call-list rows are built by `line(...)`, clipped to each group's window. `effectiveRoster` (saved role wins, otherwise the guess), `rosterChecks(sc, saved, {mand, vol, labelsSeen})` (new, role mismatch, missing, not on the Mandatory or Voluntary list, label change) and `activeList` (saved order filtered to current FT; new FT top of Mandatory, bottom of Voluntary, provisional). `holidayName` computes the CBA 9.1 holidays for any year. |
| `src/app.js` | UI: welcome/load (file picker, drag-drop, sample), calendar of entries with short names and trade tags, sidebar, tick boxes (leave, Kelly, 20h OT, certs), and the Roster and lists screen. localStorage keys `callout-helper-settings-v2` (roles, seniority, mand, vol, labelsSeen) and `callout-helper-schedule-v2` (last .ics text). |
| `src/page.html` | Layout and CSS, with `/*ENGINE*/`, `/*APP*/` and `<!--SAMPLE-->` placeholders. |
| `tools/build.js` | Inlines `src/` and `sample/sample-schedule.ics` into `Callout Helper.html`. |
| `tests/test.js` | (section 7 holds the review regressions F01 to F11 and RR01 to RR06; `loadApp` runs the real `src/app.js` against a fake page for the UI checks) Checks the importer's edge cases, holidays, every rule on hand-made feeds, future-proofing (home shift, trades, Kelly reading, role flags, missing people, label change, list placement), and a full sweep of the sample. If `private/` exists, the same sweep and Kelly checks run on the real October schedule. |
| `sample/` | Made-up-name copy of October 2026 (`sample-schedule.ics`) and roster. Safe to publish. |
| `private/` | Real schedule and expected values. Git-ignored. Never publish it. |
| `RULES.md` | Rules with SOG and CBA citations, ambiguity choices (M2 reading A) and how the rotation is read. |
| `README.md` | Plain-language guide for schedulers. |

To change a rule, edit `engine.js`, update `RULES.md` and add a test, then run `node tests/test.js && node tools/build.js`. The earlier version, built on the 2027 master calendar, is retired. It survives in the public demo repo's git history.
